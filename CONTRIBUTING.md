# Contributing

This repository holds the code and data behind a published study, so changes that alter measured results are not
accepted. Fixes to build scripts, documentation and tests are welcome.

1. Open an issue describing the problem or proposal.
2. Fork, create a branch, and keep each change focused.
3. Run `make lint test reproduce` before opening a pull request; CI runs the same steps.
4. Describe in the pull request what you tested, and on which hardware if any.
